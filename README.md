# GEMINI_LANGGRAPH_CHATBOT

This repository contains the GEMINI_LANGGRAPH_CHATBOT project.

## Files

- `app.py` - Main application entry point.
- `streamlit_app.py` - Streamlit app interface for the chatbot.
- `graph.py` - Contains the ConversationGraph class for managing chatbot conversations.
- `.gitignore` - Specifies files and folders to be ignored by git.
- `README.md` - Project documentation.

## Getting Started

1. Clone the repository.
2. Install requirements (if any).
3. Run `app.py` or `streamlit_app.py` as needed.

## Description

This project is designed for experimenting with language models and graph-based conversations using Streamlit and Python.
